MIXEL Print portable mode

While this file sits next to pdfcraft.exe, MIXEL Print keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the PdfCraftData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move MIXEL Print with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\MIXEL Print and
%LOCALAPPDATA%\MIXEL Print) instead. If PdfCraftData can't be written (for example on a read-only
drive), MIXEL Print says so and uses the per-user folders instead.
